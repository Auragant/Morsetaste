# MorseBridge App-Icon

Motiv „Morse trifft Leertaste“: eine blau umrandete Leertaste mit zwei kurzen
und einem langen mintgrünen Impuls auf einer dunkelblauen App-Kachel.

`morsebridge-icon-v1-master.png` ist der unveränderte Imagegen-PNG-Master.
Die ICO-Datei enthält RGBA-Bilder in 16, 24, 32, 48, 64, 128 und 256 Pixeln;
die separaten PNGs dienen zur Vorschau. Pillow hat die Größen mit Lanczos
erzeugt und die ICO-Datei kodiert. Der verwendete Generierungsprompt liegt in
`morsebridge-icon-v1-prompt.txt`.

Die Win32-Ressource bindet die ICO-Datei direkt in die EXE ein. Die App braucht
daher zur Laufzeit keine Bilddateien neben der EXE.
